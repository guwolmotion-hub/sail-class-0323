AE 레이어

널 레이어 (Null Layer)

형태도, 특별한 정보도 없는 깡통 레이어. 레이어 패널에는 추가되지만 화면에 아무것도 나타나지 않는다.

형태 · 색상 없음

컨트롤러 역할

여러 레이어를 널 레이어 하나에 연결해두면, 널 레이어만 조작해도 연결된 레이어 전체가 동시에 반응한다. 복잡한 애니메이션을 한 곳에서 제어할 때 핵심적으로 사용.

📦

그룹 역할

관련된 레이어들을 널 레이어 아래 묶어 논리적인 그룹으로 관리한다. 오브젝트 계층 정리 + 이동·회전·스케일을 그룹 단위로 적용 가능.

단축키
Ctrl+Alt+Shift+Y
널 레이어 생성
언제 쓰나? 카메라가 여러 오브젝트를 동시에 따라가거나, 복잡한 캐릭터 리깅처럼 다수의 레이어를 하나처럼 움직여야 할 때. 패런팅과 함께 쓰면 강력하다.

최종 출력

렌더링 — 최종 영상 출력

작업이 끝난 후 공유·납품을 위해 반드시 렌더링이 필요하다. 포맷은 특별한 사유가 없으면 H.264(MP4)를 사용한다.

권장

Adobe Media Encoder

Add to Media Encoder Queue

백그라운드에서 렌더링하므로 AE 작업을 계속할 수 있다. 배치 렌더링도 가능. 실무에서 가장 많이 사용하는 방법.

  • 출력 포맷: H.264 (MP4)
  • 렌더링 중 AE 계속 사용 가능
  • 여러 파일 동시 렌더링 지원

AE 자체 렌더링

Ctrl + M

AE 내부에서 직접 렌더 큐로 내보내는 방법. 렌더링 중 AE가 잠기지만 간단한 작업에 빠르게 사용 가능.

  • Render Queue 패널에서 진행
  • 렌더링 중 AE 작업 불가
  • 간단한 테스트 렌더에 적합

렌더링 전 필수 체크리스트

✓
전체 재생으로 최종 확인

렌더링은 시간이 걸리는 작업이므로 반드시 완전 재생으로 영상 전체를 한 번 더 확인한다.

✓
텍스트·자막 오탈자 확인

렌더 후 발견하면 처음부터 다시 해야 한다. 특히 자막의 맞춤법·타이밍을 꼼꼼히 체크.

✓
오디오 레벨 확인

음악·음성이 너무 크거나 작지 않은지, 음원이 끊기지 않는지 확인.

✓
Work Area 범위 확인

렌더링할 구간(Work Area)이 올바르게 설정되어 있는지 확인. 의도치 않은 구간이 잘리거나 추가될 수 있다.

화질 저하 주의 렌더링된 MP4를 다시 AE로 가져와서 작업하고 또 렌더링하면 압축이 중첩되어 화질이 떨어진다. 수정이 필요하면 원본 AE 프로젝트 파일에서 직접 수정하고 다시 렌더링할 것.
레이어 제어

마스크 기능

레이어의 특정 영역만 보이게 하거나, 원하는 부분을 가리는 기능.

원본 레이어 전체
+
마스크
마스크 영역만 표시

보이게 하기 (Mask)

원형·사각형·자유형 마스크로 레이어의 일부 영역만 표시. 나머지는 투명 처리되어 아래 레이어가 보인다.

예: 원형 마스크로 인물만 오려내기

가리기 (Inverted Mask)

마스크를 반전(Inverted)하면 마스크 영역은 투명해지고 바깥 영역만 표시된다. 특정 부분을 지우는 효과.

예: 로고 영역 제거, 배경 일부 제거

마스크 애니메이션

마스크 패스에 키프레임을 주면 마스크 모양이 시간에 따라 변한다. 텍스트가 선 뒤에서 나타나는 리빌 애니메이션 등에 사용.

예: 텍스트 리빌, 와이프 전환

오늘 수업 핵심 정리

  • 널 레이어 = 형태 없는 컨트롤러. 단축키 Ctrl+Alt+Shift+Y
  • 패런팅 = 부모 레이어 지정 → 자식 레이어가 따라 움직임. 널 레이어와 조합하면 강력
  • 렌더링 = 권장 포맷 H.264(MP4), Media Encoder 사용 추천. 렌더 전 전체 확인 필수
  • 마스크 = 원하는 영역만 보이게 하거나 가리는 기능. 키프레임으로 애니메이션도 가능
숙제

오늘 숙제

수업 시간에 타이틀만 만들고 뒷 장면 자막은 작업하지 않았다. 이번 주 안에 아래 내용을 완성해 제출.

1
뒷 장면 자막 전체 넣기

타이틀 이후 나오는 장면에 자막을 모두 추가. 폰트·크기·위치·타이밍을 통일감 있게 작업.

2
H.264(MP4)로 렌더링

자막 작업 완료 후 Media Encoder 또는 Ctrl+M으로 렌더링. 렌더 전 전체 재생으로 한 번 더 확인.

3
구월지점 카페에 업로드

렌더링된 MP4 파일을 카페에 업로드해 제출 완료.
